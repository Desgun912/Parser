# Парсер аренды квартир (krisha.kz → Telegram)

Ищет новые объявления на krisha.kz по заданным критериям и присылает их в Telegram.
Критерии по умолчанию: Петропавловск, цена до 145 000 ₸, 1–2 комнаты.
Меняются в файле `scraper.py` в блоке "НАСТРОЙКИ ПОИСКА".

## Что нужно сделать перед запуском

### 1. Создать Telegram-бота
1. В Telegram открой [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`, следуй инструкциям (придумай имя и username бота)
3. BotFather выдаст **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохрани его

### 2. Узнать свой chat_id
1. Открой [@userinfobot](https://t.me/userinfobot) в Telegram
2. Напиши ему что угодно — он пришлёт в ответ твой **chat_id** (число)
3. Обязательно напиши что-нибудь и своему новому боту (просто "привет") — иначе он не сможет прислать тебе сообщение первым

### 3. Создать репозиторий на GitHub
1. Зайди на github.com → New repository
2. Можно приватный (следи за лимитом 2000 мин/мес) или публичный (лимитов нет)
3. Залей туда все файлы из этой папки (`scraper.py`, `requirements.txt`, `README.md`, папку `.github`)

   Проще всего через веб-интерфейс: "Add file" → "Upload files", перетащить всё содержимое.
   Важно сохранить структуру папок — файл workflow должен лежать по пути
   `.github/workflows/scrape.yml`.

### 4. Добавить токен и chat_id в Secrets репозитория
1. В репозитории: Settings → Secrets and variables → Actions → New repository secret
2. Добавить два секрета:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1
   - `TELEGRAM_CHAT_ID` — chat_id из шага 2

### 5. Проверить, что всё работает
1. Перейти во вкладку **Actions** репозитория
2. Выбрать workflow "Krisha parser" → "Run workflow" (запуск вручную, не дожидаясь расписания)
3. Посмотреть логи запуска — если ошибок нет, при первом запуске придут уведомления
   по всем текущим объявлениям, подходящим под критерии (это нормально — дальше будут
   приходить только новые)

После этого парсер будет сам запускаться каждые 15 минут и присылать только новые
объявления, которых раньше не было.

## Если нужно поменять критерии

Открой `scraper.py`, в начале файла:

```python   
CITY = "petropavlovsk"
PRICE_TO = 145000
ROOMS = [1, 2]
```

Поменяй значения и сохрани — при следующем запуске (или после Run workflow) применятся
новые критерии.

## Если вёрстка krisha.kz изменится и парсер перестанет находить объявления

В функции `parse_listings()` в `scraper.py` нужно будет поправить CSS-селекторы
(`div.a-card`, `a.a-card__title` и т.д.) под новую структуру страницы. Дай знать —
помогу поправить.
